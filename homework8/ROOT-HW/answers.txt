1. What is the difference between struct and class?

Struct and Class are essentially identical in c++, with the only difference that the default 
accessibility is public in structs while private in classes. 

3. Why do we need our class to be derived from the TObject?

TObject is the base class for all ROOT objects. Basically by inheriting from TObject, the class we created 
automatically becomes part of the ROOT object hierarchy. This allows us to utilise the many ROOT features
for handling objects. This is important for example for memory management (allocation and deallocation etc).
